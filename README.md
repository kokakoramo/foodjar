# Food Jar v6 — 個人本機保存版

延續原 v6 HTML/CSS/JS，保留 Jar、Diary、Recap、搜尋、餐點 CRUD、主題與分享卡。

## 使用方式

直接開啟網站即可記帳，不需要登入或填入 Supabase 設定。
紀錄及照片保存在目前瀏覽器的 IndexedDB，成功寫入後才顯示儲存成功。
每次成功寫入後，會在容量允許時更新含照片的 localStorage 復原副本。主資料不存在時會先還原副本；讀取錯誤會停用儲存，避免誤寫空資料。頁面顯示保存餐數與副本狀態。復原副本與主資料仍屬同一瀏覽器，無法抵抗整個網站資料被清除；請固定使用同一瀏覽器，並保留匯出的備份檔。
第一次開啟會搬移 `foodjar_v6_state` 的既有資料；原 localStorage 備份不刪除。
全新使用者從空罐子開始。不同月份的預算獨立，未設定月份沿用 v6 的原預算。

設定頁可匯出 JSON（含本機照片）並還原備份。還原會取代目前紀錄並先要求確認。
資料不會自動跨裝置同步；清除網站資料、無痕工作階段結束或瀏覽器回收空間可能造成資料遺失。
請定期備份。原雲端 HTTPS 圖片連結不是嵌入式照片，仍依賴原服務可用性。

## PWA

包含 192 / 512 px FJ 字樣圖示。示範餐點缺少的 PNG 改用既有餐點 Emoji。
核心檔案完整才安裝新版快取；選用圖示失敗不會讓整次安裝失敗。
僅快取本站明列的靜態檔案，不快取 API、私人圖片或帶查詢參數的 URL。
更新等待舊分頁關閉，避免在同一分頁混用程式版本。更新後關閉所有 Food Jar 分頁再開啟。
首次連網載入並完成安裝後，標準網站網址可離線開啟；帶查詢參數的網址不保證離線。

## 暫停與後續

`LOCAL_ONLY: true` 停用登入及 Supabase 連線。原 cloud.js 與 SQL 保留，沒有重新啟用或驗證雲端模式。
目前空白的去背 API 設定代表使用原圖；透明 PNG 上傳會保留透明度。
真正 AI 去背、縮圖、餐點拆分尚未實作。

## 罐子互動

採用隨網站提供的 Matter.js 0.20.0（MIT），不需連線 CDN。新增並保存餐點後回到罐子播放落下動畫；拖曳貼紙可推動其他食物，輕點仍開啟詳情。方向鍵也能移動已聚焦貼紙。
碰撞音效在使用者互動後啟用，可用罐子下方按鈕關閉，偏好保存在本機。減少動態效果設定會略過入罐動畫；頁面隱藏、切換分頁或物件靜止時停止更新。
沿用最多顯示 14 筆的罐子，其他紀錄可透過 +N 查看 Diary；價格影響貼紙大小，擁擠時等比例缩小。碰撞輪廓為圓角方形近似，並非 AI 食物輪廓。拖曳位置只維持當前畫面，重開會重新堆放，餐點紀錄不受影響。

## 新增餐點體驗

金額下方提供早餐、午餐、晚餐、飲料、甜點、宵夜快捷按鈕。成功保存後中央呈現食物、原本金額與本餐增額，累加完成後投入罐子。出現、累加與入罐均有低音量音效，共用音效開關；減少動態效果時省略大幅移動。動畫開始前資料已寫入，關掉動畫畫面不會撤回紀錄。

罐子互動區在手機版約增加 22% 寬度及 46% 可用面積；食物價格的相對尺寸維持一致，讓更多餐點可以自然堆疊。
